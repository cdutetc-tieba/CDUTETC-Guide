# 🛡️ 防诈骗专题

::: danger 致新生同学
每年开学季都是诈骗案件的高发期。不法分子常利用新生"人生地不熟""急于适应新环境"的心理，设置各种骗局。请务必提高警惕，牢记"天上不会掉馅饼"，守住自己的钱袋子！
:::

## ⚠️ 常见骗局分类

新生入学期间最常见的四类骗局，点击下方卡片查看详细防范指南：

<div class="fraud-grid">

### 📞 [电话卡强买强卖](./phone-card-scam)

- **特征**：以"校园专属套餐""学长推荐"为名强制推销
- **手段**：虚假宣传、捆绑消费、恐吓威胁
- **建议**：运营商正规渠道办理，保留维权证据

---

### 🛏️ [床上用品推销](./bedding-scam)

- **特征**：冒充学校老师/学姐学长上门推销
- **手段**：假冒身份、虚假优惠、质量低劣
- **建议**：学校统购渠道更放心，私下交易需谨慎

---

### 📚 [日语宣传](./japanese-propaganda)

- **特征**：散发"免费学日语"传单诱导报名
- **手段**：虚假承诺、高额收费、合同陷阱
- **建议**：理性看待培训宣传，核实机构资质

---

### 💬 [QQ群聊](./qq-group-scam)

- **特征**：冒充新生群管理员发布虚假信息
- **手段**：钓鱼链接、刷单兼职、冒充熟人
- **建议**：认准官方群，谨慎点击陌生链接

</div>

## 🚨 紧急联系方式

| 紧急情况 | 联系方式 |
|---------|---------|
| **校园报警** | 学校保卫处电话（入学须知中查询） |
| **报警求助** | **110** |
| **电信网络诈骗报警** | **96110**（反诈专线） |
| **消费者投诉** | **12315** |
| **校园热线** | 学校官方公众号/迎新群 |

## 💡 通用防诈原则

1. **不轻信**：陌生来电、短信、好友申请一律警惕
2. **不透露**：身份证号、银行卡号、验证码不外泄
3. **不转账**：未经核实绝不向陌生账户转账
4. **不点击**：陌生链接、二维码不随意扫码
5. **多核实**：遇到可疑情况及时联系学校老师或警方

::: tip 💪 温馨提示
如遇可疑情况，**立即停止操作**，第一时间联系学校辅导员或拨打 **96110** 反诈专线咨询。记住：被骗后及时报警，仍有挽回损失的可能！
:::
