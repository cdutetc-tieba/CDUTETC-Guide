# 欢迎来到三本

> 无论有多少人以怎样的方式祝福，每年有99.93%的人考不上清北，98.5%的人考不上985，96%的人考不上211。我们的教育资源是如此匮乏，以至于即使奇迹降临，一个人考上的后果不过是另一个人落榜。
>
> 因此，如果你有足够的幸运，足够的努力，足够的聪明考上顶尖大学，我祝福你在经过漫长的求学生涯后，仍然保持一定理想主义；我祝福你谋求改变这种匮乏，而不是以人上人自居；我祝福你仍然对最朴素的公义怀有敬畏，而非只谋求自己的私利；我祝福你发现即使所有的弊病都无法拯救，仍然愿意爱惜羽毛，而非同流合污。

## 高考结束了，排序没有

来到三本，首先需要承认的不是“高考不代表一切”，而是它确实代表了一些东西。它把人送进不同的学校，而学校的名字又会继续参与之后的筛选。有些门槛会因此提前打开，有些信任则需要花更长时间才能取得。学历不是命运，但它也不是一张可以靠自信抹去的纸。

真正麻烦的是，高考留下的不只有分数，还有一种看待自己的方式。我们习惯了被排在一张表上，于是进入大学以后，仍然忍不住寻找下一张表：绩点、证书、竞赛、考研院校，或者任何能够证明“我其实不差”的东西。它们当然可能重要。问题在于，当一个选择主要是为了洗掉过去的失败，它就很难再接受诚实的追问：我究竟想从中得到什么？它值得我付出几年吗？如果没人羡慕，我还会不会做？

三本学生很容易在两种说法之间摇摆。一种说学历决定一切，于是四年还没开始，结局已经被提前宣布；另一种说平台根本不重要，只要努力就能完成逆袭。前一种把现实说成宿命，后一种则把结构性的差距包装成个人意志的考试。它们都省略了真正困难的部分：承认一些门槛暂时存在，同时继续判断哪些事情仍值得做。

## 没有人替你决定什么值得

学校会给出培养方案、课程表和毕业要求。它们规定了怎样拿到一张文凭，却不会替每个人回答，四年里应该成为怎样的人。

这并非三本独有，只是在资源较少、信息较稀薄的地方，服从安排的代价可能更晚才显现。课程及格不等于理解了专业，参加项目不等于获得了能力，忙碌也不等于正在接近目标。一个人可以把每天排得很满，最后只证明自己很擅长完成别人布置的事情。

因此，大学里重要的变化不是从“不努力”变得“努力”，而是开始为自己的投入寻找理由。为什么考研？为什么参加这场比赛？为什么学这门技术？这些问题没有体面的统一答案。为了更好的工作、为了研究兴趣、为了离开不喜欢的行业，甚至只是为了获得更宽裕的生活，都可以是理由。唯独“大家都这样做”不够，因为承担时间和失败的人最终只有你。

## 不要用逆袭解释四年

“逆袭”是一个诱人的词。它承认起点不平等，又暗示只要结局足够漂亮，过去承受的一切便有了意义。但人生不是一场等待翻盘的比赛。若你把全部价值押在下一次升学、下一份录取或下一场筛选上，高考思维并没有消失，它只是换了考场。

你仍然需要成绩，需要知识，也可能需要一张更有分量的学历。这些都不值得羞于承认。真正需要警惕的，是把它们当成对自尊的治疗。学历可以改变一部分机会，却不能自动给人判断力；证书可以通过一次筛选，却不能告诉你愿意为什么长期工作；一次成功可以纠正别人对你的低估，却未必纠正你对自己的误解。

所以，不必急着证明三本不重要。它当然会在一些时刻影响你。也不必把四年都花在反驳这个标签上，因为持续反驳仍然意味着由它来规定你是谁。

欢迎来到三本。这里不会天然使人成熟，也不会自动埋没谁。它只是更早地把一个不太体面、却无法回避的问题交到你手中：当学校的名字不能替你赢得信任，当既定道路也未必通向你想要的生活，你准备依据什么安排自己的时间？
