# 三本人，你要自信

> 「你来了」
>
> 「我来了」
>
> 「你本不该来的」
>
> 「可是我已经来了」

自信大概是三本学生最常被劝告，也最难真正拥有的东西。

有人说，既然已经来了，就不要再管学校好坏，靠自己努力便是。还有人喜欢举出几个从普通学校走出去的成功者，仿佛他们足以证明平台无关紧要。这些话听上去是在鼓励，实际没有回答最具体的问题：当周围缺少信息、榜样和可靠反馈时，一个人怎样知道自己正在做的事是否值得？

这篇文章所说的自信，不是相信自己一定能赢，而是相信自己能够逐渐形成判断，不因机会稀缺就抓住遇到的每一样东西。

## 稀缺的不只是机会

谈到学校差距，人们最容易想到实验室、竞赛名额、实习和校友。这些当然重要，但真正难以察觉的差距往往发生在机会出现之前：你是否知道什么值得争取，怎样的成果才算合格，一条道路需要提前多久准备，以及某位老师承诺的“项目经历”究竟有没有价值。

在信息密集的环境里，一个人不必走很远就能看到参照。他可以从高年级学生那里知道某门课应该学到什么，从同伴的作品里发现自己的不足，也更容易遇到已经走过目标路径的人。资源较少的环境则可能形成另一种循环：因为周围没人做过，所以没人知道怎样开始；因为没人知道标准，一点粗糙的成果也容易被当成优秀；等到真正进入校外竞争，差距才一次性暴露出来。

这也是为什么“学校给了什么就用好什么”仍然不够。资源并不因为稀缺就自动珍贵。一个缺少指导、只有杂务的项目，不会因为机会难得就变成好项目；一场只为填满简历的比赛，也不会因为拿到奖状就产生能力。越是缺少选择，越要警惕把被分配到的东西解释成最适合自己的东西。

## 向外寻找尺度

学校能够给你课程、老师和同学，却不应该成为你判断自己的全部尺度。

如果想做技术，就去看成熟项目怎样组织，真实岗位要求解决什么问题；如果想做研究，就去读这个领域的论文，了解一个问题如何被提出、证据如何成立；如果准备考研，就面对目标院校的试题、录取要求和竞争，而不是只看身边同学复习到了哪里。所谓向外看，不是把名校学生想象成更高级的人，而是找到不由本校气氛决定的标准。

这会带来一些不舒服的发现。你可能意识到课堂上的高分并不等于掌握，校内受到表扬的作品拿到外面并不突出，准备很久的方向也未必适合自己。许多人宁愿留在熟悉的比较中，因为只要参照足够近，自我感觉就不容易破裂。

但依靠降低尺度得到的自信，经不起一次真正的筛选。外部反馈有时不公正，也可能受表达方式和偶然因素影响；它不是终审判决，却比封闭环境里的相互肯定更接近你将要面对的世界。成熟的做法不是服从每一次评价，而是比较来自不同地方的结果，逐渐分辨哪些问题确实需要修正。

## 自信是一种判断能力

资源丰富的人也会浪费资源，资源有限的人也可能被虚假的机会消耗。真正产生差别的，不只是手里有什么，还有能否识别一件事的质量：带你的老师是否认真，项目能否接触核心工作，比赛是否要求真实能力，一段经历结束后究竟留下了什么。

这种识别能力最初一定不可靠。它只能从比较中形成：查看更成熟的成果，询问真正做过的人，核对公开要求，再用一次小规模尝试检验判断。你不需要先认识很多厉害的人，才能开始做这些事；但需要接受，熟悉和热闹都不能代替质量。

自信因此不是一种情绪，而是判断经过修正之后留下的稳定感。你知道自己可能看错，也知道可以继续查证；知道某些资源得不到，也不会因此把次品当成珍贵；知道校内评价的边界，所以愿意把作品和能力放到更大的尺度下检验。

“可是我已经来了”不是认命，也不是宣战。它只是承认处境，然后开始学习一件学校未必会专门教你的事：在资源有限的地方，判断什么值得投入。
