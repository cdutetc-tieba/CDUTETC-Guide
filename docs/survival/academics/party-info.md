# 入党了解

::: tip 💡 学姐经验
学姐之前当过一段时间团支书，也有一些了解。之前一直有很多同学在问入党的条件和流程这些，也承诺大家后面会发，今天就编辑好来发啦！
:::

## 入党条件

::: danger ⚠️ 基本要求
- **年龄满 18 岁**
- **共青团员**
- **无宗教信仰**
:::

## 时间周期

成为党员，**至少需要时间：3 年**

| 年份 | 阶段 |
|:----:|------|
| **第一年** | 选出入党积极分子，上党课，考试 |
| **第二年** | 从众多入党积极分子中，选出少部分优秀的人，成为预备党员 |
| **第三年** | 在预备党员一年中，不得犯事，不得违规，否则延迟转正或者取消预备党员资格 |

## ⚠️ 重要注意事项

::: danger 🔴 红线警告
**不要挂科！！！不要违纪！！！**

- 一旦挂科，则取消评选资格
- 优先考虑班长、团支书、及绩点排名前三的同学
:::

## 入党流程

```plaintext
递交入党申请书 → 入党积极分子 → 发展对象 → 预备党员 → 正式党员
```

## 详细流程

### 1. 递交入党申请书

入学后辅导员会组织，想入党的同学写申请书即可。

### 2. 团员优先推荐

| 项目 | 说明 |
|------|------|
| **时间** | 每年 4 月、11 月 |
| **条件** | 递交入党申请书满半年，入党动机端正，无挂科，关心同学，热爱集体等 |

### 3. 入党积极分子确定

| 项目 | 说明 |
|------|------|
| **时间** | 每年 4 月、11 月 |
| **注意** | 入党积极分子需要经常写思想汇报，**每季度一份** |

### 4. 参加党校学习

| 项目 | 说明 |
|------|------|
| **时间** | 每年 5 月中旬、11 月中旬 |
| **注意** | 学习结束会有考试 |

### 5. 成为发展对象

> 成为入党积极分子**一年后**才有机会成为发展对象。

### 6. 成为预备党员（预备期 1 年）

### 7. 预备党员转正

## 需要准备的材料

1. **入党申请书**
2. **每季度 1600 字以上的思想汇报**
3. **党课笔记 + 心得**
4. **入党志愿书 + 政审材料**
5. **学习强国**
6. **转正申请书**

## 考核环节

1. **党课考试**
2. **政审背调**
3. **转正答辩**

---

::: warning 💡 名额说明
学院每批没批入党积极分子当中，每个班是 **1 个预备党员名额**（有些班级最多 2 个名额）。

入党的过程是辛苦且漫长的，要做好心理准备，而且能在大学入党的也是很少部分人！

> **再次强调：想入党，千万别挂科和违纪！**
:::
