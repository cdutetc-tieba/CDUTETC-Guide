# 不要温和地走进那个厕所

这个栏目放在具体的考研、留学和就业指南之前。

它暂时不回答数学应该刷几轮、简历如何排版、申请材料怎样准备。方法只有在目标成立之后才有意义。在投入几个月甚至几年以前，更需要先问：我希望这条路改变什么，它凭什么能够改变，以及最普通的结果是否仍然值得承担。

学校里的出路讨论很容易从结论开始。考研的人交换院校名单，就业的人比较行业，准备留学的人计算排名，却很少有人愿意承认，自己可能还没有想清楚为什么出发。一个方案越具体，越容易制造已经作出决定的错觉。

这里的文章不替任何道路背书，也不把没有明确方向的人称作逃避。它们只负责把目的、训练、成本和退路摊开。后续的经验文章则应来自真实投稿：作者走过哪条路，就讲清自己的背景、选择、失败和结果，不把一个人的经历包装成所有人的答案。
