# 毕业之后，你想解决什么问题？

临近毕业时，人们习惯问：“考研还是就业？”

这个问题看似直接，其实把顺序弄反了。考研、就业、考公和留学都是手段。只有先知道自己需要解决什么，才可能判断哪种手段有效。否则，选择往往只是跟随身边人数最多、看起来最体面或最能延迟焦虑的那一条路。

## 出路不是身份

“考研党”“就业党”和“考公党”这些称呼，容易把一个阶段性的方案变成身份。加入其中之后，人会开始收集支持本方的理由：准备考研的人反复强调学历门槛，准备就业的人强调工作经验，考公的人谈稳定。讨论逐渐变成互相证明谁更清醒，而不是检查每条路到底通向哪里。

考研可能提供新的学历、专业训练和校园时间，也可能只是把就业推迟几年；工作可以带来收入和真实的职业反馈，也可能把人固定在缺少成长的岗位；考公能够换取相对明确的职业结构，却要求接受具体的工作内容、地区和晋升方式。任何选择都不能只用它最好的一面来命名。

所谓“躺平”更不是一个与考研、就业并列的选项。有些人只是暂时没有答案，有些人需要处理健康或家庭问题，也有人确实在逃避。把这些不同处境塞进同一个带有贬义的词，只会让焦虑更快，却不会让决定更准确。

## 先把问题说具体

“我想提升自己”无法支持一项需要长期投入的决定。你究竟希望改变的是学历筛选、专业方向、知识训练、工作城市，还是收入？这些目标可能指向完全不同的道路。

如果目标岗位明确要求更高学历，读研可能是在解决准入问题；如果只是缺少一项可练习的技能，几年研究生教育未必比项目、实习或职业培训更有效。想换专业的人需要确认目标项目是否真正接受并训练跨专业学生；想离开当前环境的人则要区分，自己是在前往一个确定的地方，还是只想暂时不留在原地。

就业也不是一个完整答案。行业、岗位、城市和组织规模会形成完全不同的生活。说“我先工作看看”，至少应该知道准备看什么：自己能否适应这类任务，现有能力在市场上如何定价，还是某个行业是否值得长期投入。没有观察目标的尝试，只会增加一段经历，不一定增加认识。

## 比较普通结果

人们选择出路时，常用成功案例估算收益，却用自己的全部处境承担风险。考研看到的是跨层次录取，就业看到的是高薪 offer，留学看到的是名校和海外生活。真正应该比较的，是自己更可能得到的普通结果。

这要求把路径拆开来看。考研不只是一张录取通知，还包括备考期间放弃的实习和收入、没有录取时的去向，以及入学后的课程、导师和培养质量。工作不只是一份起薪，还包括具体任务能否积累、劳动条件是否能够承受、下一份工作会怎样评价这段经历。留学也不能只看学校排名，还要把费用、语言、就业资格和回国后的认可放进同一张账里。

最好的结果可以说明一条路存在可能，普通结果才更适合用来决定是否出发。

## 在决定以前接触现实

出路选择不可能等到信息完整以后再做，但可以在付出主要成本之前，先接触它最核心的部分。

准备考研，可以先读目标专业的培养方案、导师介绍和专业课材料，而不只是收集分数线；考虑就业，可以查看一批真实岗位，完成一次投递或短期实践，看看市场如何评价现有能力；考虑考公，应先阅读岗位要求和实际工作内容，再判断自己追求的是这份工作，还是“稳定”这个抽象词。留学则更需要核对项目课程、总成本和毕业去向，而不是先从中介那里获得一套完整梦想。

这些尝试不会替你作出决定，却能暴露一个目标是否只有想象、没有内容。越晚接触现实，已经投入的时间越容易迫使人继续走下去。

## 选择是暂时的承诺

没有哪次选择能够一次解决整个职业生涯。读研之后仍要决定就业或继续研究，第一份工作也不会永久锁定方向。认识到这一点，不是说所有决定都可以随时反悔，而是不要要求一个二十岁左右的人先给出终身答案。

你需要的是一段有期限的承诺：在接下来的阶段投入什么，用什么结果判断它是否有效，出现什么情况时重新选择。承诺使行动成为可能，期限则防止沉没成本替你继续决定。

毕业之后选择什么，最终取决于你要解决的问题。不要从一个体面的答案出发，再替它寻找理由。先把问题说清楚，然后选择成本能够承担、机制能够理解、普通结果也可以接受的那条路。
