# 留学

这里主要讨论本科毕业后申请境外硕士。学校背景会影响部分项目的筛选，但它不是唯一变量；专业匹配、成绩、语言、经历、预算和申请年份都会改变结果。本栏目不会给出“某地区容易录取”的保证，也不按排名替你生成选校名单。

先判断留学能否解决你的问题，再决定把时间和钱投向哪里。没有想清这一点，越早找中介，往往只是越早得到一份看起来完整的方案。
