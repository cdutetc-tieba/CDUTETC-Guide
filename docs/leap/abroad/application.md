# 选校与申请

这个版块负责两件事：先把模糊的“想去某个国家”变成一组能够比较的具体项目，再把确定要申请的项目推进到提交。它不提供一张通用选校名单，也不替代各国家页中的制度信息。

## 先确定项目解决什么问题

先写下一条可以核验的目标，例如转向某个专业、获得某类岗位所需训练、进入特定地区，或为研究型深造补足方法。若目标只是“提升学历”，排名很容易成为唯一筛选标准，课程和成本反而被忽略。

打开[留学指南/北/西/东](./guide/)，选择两到三个制度和预算都可能承受的地区，再从学校官网寻找项目。第一轮项目池可以稍宽，但每个项目都必须有保留理由。

## 用三轮筛选缩小项目池

### 第一轮：排除硬条件不符

核对本科专业、先修课程、成绩口径、语言、工作经验和作品集。官网没有说明普通院校背景是否被接受时，应联系招生办公室，不用中介的口头判断补齐空白。

### 第二轮：比较课程与结果

阅读必修课、选修范围、考核方式、毕业项目和实习安排。再查询毕业生去向、当地岗位要求和继续读博条件。项目名称相同，不代表训练内容相同。

### 第三轮：比较代价与可逆性

把学费、生活费、押金、学制和毕业后求职期放在一起计算。高排名项目不一定值得更高负债；录取概率较高的项目也不一定值得入读。

## 建立一张能执行的项目表

每个候选项目至少记录：

- 项目名称、授课语言、学制和开学时间；
- 接受的本科专业、先修课程与成绩要求；
- 是否说明中国院校背景、成绩换算或最低学位等级；
- 语言考试种类、单项要求以及能否后补；
- 学费、申请费、押金或留位费及退款规则；
- 申请轮次、材料清单和预计出结果时间；
- 课程结构、毕业要求、实习安排和就业资格；
- 信息来源与最后核验日期。

把项目标记为“待核实、可申请、已提交、已录取、已放弃”，并为待核实项写下下一步动作。项目表的价值不是收集信息，而是让申请状态和缺口一眼可见。

## 申请层次按证据划分

“冲刺、主申、保底”不能只按排名划分，应按你与公开门槛的匹配证据判断：

- **要求明确匹配**：官网公布的硬门槛能够满足，课程和目标也一致；
- **存在需要确认的条件**：例如跨专业、院校背景、先修课或语言后补；
- **明显依赖例外**：核心门槛不满足，只能期待招生方放宽。

第三类可以少量尝试，但不能承担保底功能。任何境外项目都不存在严格意义上的保录；真正的退路是你愿意接受的国内升学、就业、延期或下一申请季方案。

## 按申请顺序推进

1. 建立项目池并核对硬门槛。
2. 向教务部门确认成绩单、在读证明、评分说明等材料的办理方式。
3. 安排语言考试和推荐人，给出分、送分与签字留出缓冲。
4. 按项目课程和申请问题准备简历、陈述、作品集或研究计划。
5. 提交后记录申请号、补件、面试、押金截止日和退款规则。
6. 收到录取后重新比较课程、总成本和去向，不按 offer 到达顺序做决定。

成绩单、语言成绩和推荐信解决资格与可信度；个人陈述和简历解释经历与项目之间的联系。不要先写万能文书再替换学校名。生成式 AI 可以帮助检查结构和语言，但事实、项目经历和个人动机必须由本人确认。

## 何时删掉一个项目

当核心门槛无法满足、课程不能支持目标、总预算突破家庭上限，或关键材料无法按时取得时，应删减项目、延期或换路。申请费和已经花掉的备考时间都是沉没成本，不能证明继续投入合理。

## 提交前核对

1. 打开项目官网，而不是聚合平台或中介表格。
2. 核对当年申请轮次和入学要求，保存网页与日期。
3. 把不确定项写成具体问题，联系招生办公室。
4. 计算提交后不可退的费用，再决定是否申请。
5. 保存提交版本、付款凭证和学校邮件，避免补件时找不到依据。
