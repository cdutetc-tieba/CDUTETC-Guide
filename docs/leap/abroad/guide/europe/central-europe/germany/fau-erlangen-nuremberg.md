# 埃尔朗根-纽伦堡大学

**QS 2027：=218。** FAU 在电子、材料、计算机和医学工程之间有较多交叉，适合本科课程基础较完整、希望进入工业与医疗技术相关方向的学生。

## 值得查的方向

- Communications and Multimedia Engineering；
- Computational Engineering、数据与人工智能；
- 材料、能源、医疗工程和先进制造。

## 先排除什么

确认课程对应校区、入学学期和能力评估方式。部分项目对数学、算法、信号或工程学分有明确要求，动机信不能替代缺失模块。
