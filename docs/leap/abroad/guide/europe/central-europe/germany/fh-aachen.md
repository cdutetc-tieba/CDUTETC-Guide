# 亚琛应用科学大学

**QS 2027 综合榜：未进入。学科例外。** 应用科学大学的培养和评价重点与研究型综合大学不同。FH Aachen 只适合重视应用工程、实验和产业训练，且已经确认学位类型符合自身目标的人。

## 值得查的方向

- 航空航天、机械、汽车和能源工程；
- 电子、信息与应用计算机；
- 与企业项目或实验训练结合的工程课程。

## 先排除什么

先确认项目授课语言、是否要求德语、课程是否包含强制实习，以及应用科学大学学位对你的读博或回国求职目标是否合适。不能用“更好申请”替代这些判断。
