# 德国

## 学校与项目特点

德国综合性大学通常更偏研究和理论，应用科学大学更强调实践，但培养方式仍要看课程。多数公立大学连续型硕士通常不收学费，不过部分州、高校和继续教育项目存在例外。[DAAD：学习费用](https://www.daad.de/en/studying-in-germany/living-in-germany/finances/)

德国申请中，课程和学分匹配通常比综合排名更接近硬门槛。

## 通用申请门槛

- 取得满足德国高校入学资格要求的本科学位，并完成中国申请者所需的 APS 审核。
- 本科专业、课程内容和学分与硕士项目匹配。
- 达到项目要求的德语或英语水平。
- 个别项目要求 GRE、模块手册或特定成绩等级。

## 申请方法与窗口

项目可能通过大学系统直接申请，也可能经过 uni-assist。冬季学期申请常集中在春季至初夏，夏季学期常在前一年冬季开放，具体以项目为准。

1. 用 [DAAD International Programmes](https://www2.daad.de/deutschland/studienangebote/international-programmes/en/)找项目。
2. 对照课程与学分准备成绩单、培养方案和课程描述。
3. 提前办理 [APS](https://www.aps.org.cn/)，确认是否还需 VPD。
4. 在学校或 uni-assist 系统提交。

## 常用申请材料

学位与毕业材料、成绩单、APS、语言成绩、简历、动机信、课程描述或模块手册、护照。认证要求参考 [uni-assist 中国材料说明](https://www.uni-assist.de/en/tools/info-country-by-country/details-country/country/cn/)。
