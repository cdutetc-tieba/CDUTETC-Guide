# 欧洲

欧洲各国学制、收费和申请平台差异很大。“欧陆”不是一种统一申请制度。英国和爱尔兰的英语授课型硕士较集中；德国更看重课程匹配；意大利需要衔接大学录取、Universitaly 预注册和签证。

## 北欧

丹麦、瑞典、芬兰和挪威等国有英语授课项目，但学费、奖学金、生活成本与就业语言要求差异明显。当前不设空白国家页，后续按官方资料逐国补充。
