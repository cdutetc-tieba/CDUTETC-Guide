# 纽卡斯尔大学

**QS 2027：149。** 纽卡斯尔的主要参考价值是官网公开中国院校分层，普通本科申请者可以先判断资格，再调查工程、计算机、能源和城市相关课程。

## 值得查的方向

- 电气、机械、化工、土木和海洋工程；
- 计算机、数据与网络安全；
- 能源、城市规划与可持续基础设施。

## 先排除什么

先在中国申请说明中确认本科院校层级，再把对应均分映射到具体项目。学校分层只解决最低资格，不代表热门课程会按最低线录取。
