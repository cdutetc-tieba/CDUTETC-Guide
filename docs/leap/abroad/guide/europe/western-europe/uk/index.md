# 英国

## 学校与项目特点

英国授课型硕士通常课程密集，许多项目可在一年完成，也有转换专业课程。学制短能减少离开职场的时间，但学费、课程、毕业项目和求职准备会集中在同一年。[Study UK 研究生学习介绍](https://study-uk.britishcouncil.org/en/plan-studies/ways-learning/postgraduate)

学校会自行解释中国学历和成绩。有的按中国院校类别给出不同均分，有的只在内部使用认可名单，因此 QS 排名不能直接换算成录取难度。

## 通用申请门槛

- 取得受认可的本科学位；具体项目可能要求相关专业和先修课程。
- 达到项目针对中国申请者的均分或学位等级要求。
- 提交项目接受的英语成绩；总分、单项和能否后补须看项目页。
- 设计、建筑等项目可能要求作品集，部分商科项目可能要求工作经验或额外考试。

## 申请方法与窗口

多数授课型硕士通过大学网申系统直接申请。次年秋季入学项目常在前一年秋季开放，部分项目滚动审理，满位后提前关闭。奖学金、热门项目和语言班应更早准备。

1. 在课程目录确认项目、入学月份和申请要求。
2. 在大学网申系统上传材料。
3. 按要求补交语言、推荐信或其他文件。
4. 收到录取后核对条件、押金、CAS 与签证时间线。

## 常用申请材料

成绩单、在读证明或学位证与毕业证、英语成绩、个人陈述、简历、推荐信、护照。文件是否需要翻译、是否接受后补，以学校说明为准。
