# 爱尔兰

## 学校与项目特点

爱尔兰的英语授课硕士多为一年制，也有更长或含实践环节的项目。计算机、工程、商科、制药和生命科学较常见。选择时应同时看课程、城市产业和实习条件。

## 通用申请门槛

- 取得受认可的本科学位，满足项目要求的专业背景和成绩。
- 学校自行换算中国本科成绩，不能跨校套用同一个均分门槛。
- 达到项目认可的英语总分和单项要求。
- 部分课程要求工作经验、作品集、编程或数学基础。

## 申请方法与窗口

申请入口可能是学校系统，也可能由指定平台承接。秋季入学项目常在前一年秋季陆续开放，部分项目滚动审理并在满位后关闭。

1. 在项目页核对入学要求、学费和截止日期。
2. 按学校要求进入对应网申系统。
3. 上传材料并跟踪推荐信、语言和补件状态。
4. 录取后核对押金、住宿、签证与保险安排。

## 常用申请材料

成绩单、在读证明或学位材料、英语成绩、个人陈述、简历、推荐信和护照。部分项目要求课程描述、作品集或工作证明。
