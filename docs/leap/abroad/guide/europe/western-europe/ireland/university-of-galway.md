# 戈尔韦大学

**QS 2027：275。** 戈尔韦的医疗技术、数据、工程和海洋相关方向与当地产业及研究平台联系较强，适合目标不只集中在都柏林的申请者。

## 值得查的方向

- Biomedical Engineering、医疗器械与健康数据；
- 计算机、数据分析、电子与机械工程；
- 海洋、环境和可持续发展相关课程。

## 先排除什么

先确认项目是课程型还是研究型，所谓 industry project 或 placement 是否为必修、是否保证获得。非都柏林城市也不等于住宿容易，应查看当年住宿信息。
