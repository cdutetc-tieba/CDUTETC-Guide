# 都灵理工大学

**QS 2027：=206。** 都灵理工项目集中在工程、建筑和设计，机械、汽车、电子与制造方向尤其适合本校工科背景定向调查。

## 值得查的方向

- Automotive、Mechanical、Mechatronic Engineering；
- Electronic and Communications Engineering；
- Architecture、Urban Planning 与 Systemic Design。

## 先排除什么

先查专业匹配和非意大利学历轮次。建筑与设计项目可能要求作品集；工程项目也可能逐项看数学和专业课程。不要因米兰理工竞争更强，就自动把都灵理工视为保底。
