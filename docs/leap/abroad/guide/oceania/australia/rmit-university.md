# 皇家墨尔本理工大学 RMIT

**QS 2027：=119。** RMIT 在技术、设计和建筑方向具有清晰定位。适合看重项目实践和作品产出的人，不适合只把“墨尔本”与综合排名当作理由。

## 值得查的方向

- 工程、制造、航空与项目管理；
- 计算机、数据、网络安全；
- Design、Architecture、Media 与 Built Environment。

## 先排除什么

确认项目所在校区、设施使用、作品集要求和专业认证。RMIT 还有海外与合作办学地点，申请时必须核对实际授课校区。
