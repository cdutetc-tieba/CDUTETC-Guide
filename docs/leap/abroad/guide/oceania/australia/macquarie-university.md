# 麦考瑞大学

**QS 2027：=126。** 麦考瑞适合数据、精算、商科和健康方向，学校位于悉尼产业区，但区位价值只有在课程和预算同时匹配时才成立。

## 值得查的方向

- Data Science、Information Technology、Cyber Security；
- Actuarial Studies、Business Analytics、Finance；
- Linguistics、Health 与相关专业课程。

## 先排除什么

比较课程中的数学和编程深度，不要因名称含 analytics 就默认适合技术岗。同步计算悉尼住宿与通勤成本，核对实习是否需要自行竞争。
