# 科廷大学

**QS 2027：189。** 科廷的主要理由是西澳资源产业以及矿业、能源、地质和工程方向。若目标与这些行业无关，地理位置未必构成优势。

## 值得查的方向

- Mining、Metallurgy、Petroleum 与能源；
- Civil、Mechanical、Electrical Engineering；
- Information Technology、Project Management。

## 先排除什么

确认课程所在校区、专业认证和西澳岗位结构。资源行业具有周期性，不能把学科排名直接等同于毕业时的岗位数量。
