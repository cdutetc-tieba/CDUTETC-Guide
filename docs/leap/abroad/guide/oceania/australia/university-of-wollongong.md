# 伍伦贡大学

**QS 2027：195。** UOW 适合工程、材料和计算机背景与悉尼院校做成本、课程和城市选择对照，不应因靠近悉尼就假设共享相同岗位便利。

## 值得查的方向

- Materials、Mechanical、Civil 与 Mining Engineering；
- Computer Science、Information Technology、Cyber Security；
- Supply Chain 与专业型商科。

## 先排除什么

确认实际校区、到目标岗位城市的通勤边界、课程认证和实习方式。不同校区课程不能只按学校名称合并判断。
