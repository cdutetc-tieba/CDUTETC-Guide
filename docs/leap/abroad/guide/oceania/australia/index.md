# 澳大利亚

## 学校与项目特点

澳大利亚课程型硕士项目较多，常见学制为一至两年，也有研究型硕士和衔接课程。申请流程标准化不等于项目质量相同，必须查看必修课、行业认证、毕业要求和校区。

## 通用申请门槛

- 完成受认可的本科学位，达到项目对成绩和专业背景的要求。
- 满足英语总分和单项要求。
- 专业资格项目可能要求先修课、作品集、工作经验或更高语言成绩。
- 学生签证课程应能在 [CRICOS](https://cricos.education.gov.au/)查询。

## 申请方法与窗口

通常通过大学官网直接申请，也可经学校授权代理。二月和七月是常见开学期，部分项目只有一个入学期。建议至少提前 4 至 8 个月核对申请、签证和住宿时间。

1. 在官方大学列表和学校课程目录寻找项目。
2. 核对中国学历要求、先修课、学制与 CRICOS 信息。
3. 提交网申并跟踪补件或条件录取。
4. 取得入学确认后办理签证。

## 常用申请材料

成绩单、在读证明或学位材料、英语成绩、护照、个人陈述或简历。研究型项目通常还需研究计划、推荐信和导师沟通。
