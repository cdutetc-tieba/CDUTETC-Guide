# 亚洲

亚洲内部的申请体系并不相似。中国香港以英语授课型硕士为主，日本需要区分研究科、导师与入学考试，马来西亚则同时存在公立大学和海外大学分校。距离较近不能替代对学制、语言环境和学位主体的核查。

## 东亚

- [中国香港](./east-asia/hong-kong/)：授课型硕士项目集中，通常直接向大学申请。
- [日本](./east-asia/japan/)：国公私立大学并存，需要区分修士直考、研究生过渡和英语项目。

## 东南亚

- [马来西亚](./southeast-asia/malaysia/)：公立大学、私立大学和海外分校并存，项目类型和学位授予主体需要逐项确认。
