# 马来西亚国民大学 UKM

**QS 2027：130。** UKM 学科覆盖完整，适合同时比较工程、信息、医学与社会科学项目，但国际生项目是否开放和授课语言需要逐项确认。

## 值得查的方向

- 工程、信息技术与人工智能；
- 医学、健康和生命科学；
- 经济、管理和社会科学。

## 先排除什么

确认项目所在校区、授课语言、模式和当年国际生轮次。官网存在学院级信息时，以项目和学院页面为准。
