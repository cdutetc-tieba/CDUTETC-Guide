# 马来西亚理科大学 USM

**QS 2027：=128。** USM 适合理工、材料、环境和健康方向，但申请前必须区分 coursework、mixed mode 与 research，三者对导师和论文要求不同。

## 值得查的方向

- 工程、材料、化学与环境科学；
- 计算机、数据和技术管理；
- 医学、药学与公共健康相关方向。

## 先排除什么

确认项目模式、校区、学制和导师要求。研究型项目不能按授课型硕士的材料和时间线准备。
