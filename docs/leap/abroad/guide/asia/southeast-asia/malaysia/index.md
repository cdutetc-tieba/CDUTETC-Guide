# 马来西亚

## 学校与项目特点

马来西亚同时有公立大学、私立大学和海外大学分校，授课型与研究型硕士并存。选择分校时，应确认学位授予主体、校区标注、课程模式和认证条件。

## 通用申请门槛

- 取得受认可的本科学位并满足项目成绩要求。
- 授课型项目通常看本科专业和英语，研究型项目还要看研究计划和导师。
- 部分跨专业项目要求先修课、工作经验或桥梁课程。
- 申请前核对院校资质与回国认证条件。

## 申请方法与窗口

可以通过学校官网直接申请，部分院校也接入 [MYCAS](https://mycas.educationmalaysia.gov.my/)。不少项目一年有多个入学期，但不是每个项目每批都招生。

1. 在 [Education Malaysia 院校检索](https://educationmalaysia.gov.my/plan-your-studies/choose-what-to-study/universities)确认院校类型。
2. 回项目官网核对课程、学制和入学时间。
3. 通过学校系统或指定平台申请。
4. 录取后按学校与 EMGS 指引准备签证材料。

## 常用申请材料

学位与毕业材料、成绩单、英语成绩、护照、照片、个人陈述或研究计划、简历和推荐信。签证文件参考 [EMGS Required Documents](https://visa.educationmalaysia.gov.my/guidelines/required-documents)。
