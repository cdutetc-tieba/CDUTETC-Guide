# 马来西亚理工大学 UTM

**QS 2027：=158。** UTM 的工科定位集中，适合机械、电子、土木、建筑和计算机背景调查专业深化项目。

## 值得查的方向

- 机械、电子、化工、土木与环境工程；
- 计算机、人工智能和网络安全；
- 建筑、城市规划与技术管理。

## 先排除什么

确认 Johor Bahru 与 Kuala Lumpur 校区、上课地点和项目模式。涉及工程师资格时，应额外核对课程认证与目标就业地的认可规则。
