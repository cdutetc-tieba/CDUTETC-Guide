# 日本

## 学校与项目特点

日本硕士阶段通常称修士课程，一般为两年。申请可能是直接参加修士选拔，也可能先以研究生身份进入研究室；英语与日语项目的材料和考核不同。是否需要提前联系导师，必须看研究科招生简章。

## 通用申请门槛

- 完成本科教育并满足研究科规定的学历资格。
- 专业背景和研究方向匹配，部分项目要求事前审查。
- 按授课语言提交 JLPT、英语成绩或两者。
- 可能需要研究计划、导师意向、笔试、面试或专业考试。

## 申请方法与窗口

四月入学最常见，也有九月或十月入学。研究科可能一年多轮招生，建议至少提前 9 至 12 个月查看简章。

1. 用 [Study in Japan 学校检索](https://studyinjapan.go.jp/en/search-for-schools/school_search.php?lang=en)寻找项目。
2. 阅读研究科当年募集要项，确认直考、研究生或英语项目路径。
3. 按要求联系导师并准备研究计划。
4. 提交资格审查与正式申请，参加考核。

## 常用申请材料

学位与毕业材料、成绩单、语言成绩、研究计划、推荐信、简历、护照和照片。部分项目要求毕业论文摘要或经济能力材料。
