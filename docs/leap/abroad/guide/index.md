# 留学指南/北/西/东

国家与地区不是申请结论，只是第一层索引。真正决定能否申请的是具体项目的专业要求、成绩口径、语言门槛和当年名额。本栏目先覆盖本校及相近本科背景学生较常比较、且能从官方渠道核对规则的目的地；没有正文的国家暂不建立空页面。

## 亚洲

- **[东亚](./asia/east-asia/)**：[中国香港](./asia/east-asia/hong-kong/)、[日本](./asia/east-asia/japan/)。前者以英语授课硕士为主，后者需要区分日语项目、英语项目与研究室制度。
- **[东南亚](./asia/southeast-asia/)**：[马来西亚](./asia/southeast-asia/malaysia/)。公立大学和海外大学分校并存，需要核对学位授予主体与项目认证。

## 欧洲

- **北欧**：丹麦、瑞典、芬兰、挪威等国。英语授课项目不少，但学费、奖学金和生活成本差异明显；正文将在资料核验后补充。
- **[西欧](./europe/western-europe/)**：[英国](./europe/western-europe/uk/)、[爱尔兰](./europe/western-europe/ireland/)。项目数量较多、英文信息完整，适合先按项目要求建立申请池。
- **[中欧](./europe/central-europe/)**：[德国](./europe/central-europe/germany/)。工科项目丰富，但专业课程匹配、APS 和申请通道是硬约束。
- **[南欧](./europe/southern-europe/)**：[意大利](./europe/southern-europe/italy/)。公立大学与英语授课项目值得调查，录取、预注册和签证流程需要分开处理。

## 大洋洲

- **[澳大利亚与新西兰](./oceania/)**：首批整理[澳大利亚](./oceania/australia/)。课程型硕士选择多，申请相对标准化，但总成本和课程含金量必须落到具体项目比较。

## 北美洲

美国和加拿大项目跨度很大，费用、先修课、科研经历和就业政策也更依赖学校与项目。当前不建立空白国家页；后续应分别整理授课型硕士、研究型项目和职业导向项目，而不是用一篇“北美申请”概括。

## 使用顺序

1. 先读地区页，理解该区域常见的学制、申请体系和语言环境。
2. 进入国家页，从列出的院校入口寻找与你专业相符的项目。
3. 把项目录入[选校与申请](../application)中的项目池，不直接照抄“推荐院校”。
4. 提交前以当年项目官网重新核对门槛、截止日期、费用和材料。

所有制度信息最后核验于 **2026 年 8 月 20 日**。此日期之后的变化以主管部门和学校官网为准。
