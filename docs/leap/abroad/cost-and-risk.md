# 算清预算与风险

只比较学费，会系统性低估留学成本。预算的作用也不是算出一个漂亮总数，而是提前知道家庭要在什么时间支付多少现金、哪些费用不能退，以及汇率或申请结果变化后还能否继续。

## 分阶段记账

申请前、录取后和入学后的支出性质不同，应分别计算：

| 阶段     | 常见支出                                 | 需要核对的风险                       |
| -------- | ---------------------------------------- | ------------------------------------ |
| 申请前   | 语言考试、成绩单、翻译、申请费、材料寄送 | 多次考试和批量申请会持续增加沉没成本 |
| 接受录取 | 留位费、学费押金、签证、体检、保险       | 截止日期、退款条件和换项目后的损失   |
| 入学前   | 机票、住宿押金、初期房租、设备           | 签证延迟、住宿变更和集中付款压力     |
| 就读期间 | 学费、住宿、生活、交通、课程材料         | 汇率、学制延长和实习收入不确定       |
| 毕业阶段 | 求职、搬迁、签证续期或回国               | 找工作时间可能超过原预算             |

每个数字旁边保留币种、来源和查询日期。换算人民币时至少计算一个不利汇率情景，不要用当日最低汇率证明“预算够用”。

## 不把兼职当成必要收入

签证允许工作，不等于能够稳定找到工作，也不等于收入足以覆盖生活费。课程强度、语言、地区岗位和工时限制都会影响结果。只有在没有兼职收入时仍能完成学业，预算才具有基本可行性。

## 在付款前确认退款规则

留位费、学费押金、住宿订金和中介服务费的退款条件可能不同。付款前保存合同和项目官网，确认签证被拒、未满足条件录取、主动放弃或学校变更课程时分别如何处理。口头承诺不能代替书面条款。

## 给预算设置停止点

可以提前约定：总预算上限、最多申请数量、语言考试次数，以及没有达到什么条件就延期或退出。停止点应在付款前确定；付完一笔以后再讨论，很容易把已经花掉的钱当成继续投入的理由。

涉及国（境）外学历认证时，应通过[教育部留学服务中心](https://portal.cscse.edu.cn/lxfwzx/gjwxlxwrz/index.html)查询制度和院校信息。能在某个平台搜索到学校，不等于具体项目、学习方式和就读过程必然符合认证要求，关键问题应直接向主管机构核实。
