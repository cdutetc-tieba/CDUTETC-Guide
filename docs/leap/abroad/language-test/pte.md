# PTE Academic

PTE Academic 是全程计算机化的英语考试，评估听、说、读、写，分数范围为 10 至 90。官方说明考试约两小时，成绩通常在 48 小时内发布，但实际时间仍可能变化。

## 报考基础信息

- 考试与报名：[PTE Academic 官方页面](https://www.pearsonpte.com/pte-academic/)
- 当前考试结构：[PTE test format](https://www.pearsonpte.com/pte-academic/test-format/)
- 预约与改期：[Booking and managing a test](https://www.pearsonpte.com/help-center/booking-managing-test/)
- 成绩与有效期：[PTE scoring](https://www.pearsonpte.com/help-center/scoring/)

## 申请前核对

先逐个确认项目和签证环节是否接受 PTE Academic，再比较考点、考位与题型。PTE 出分快不等于更容易达到项目要求；如果目标项目覆盖不足，不应仅为机考便利切换。
