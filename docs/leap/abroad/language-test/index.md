# 语言考试总览

语言成绩服务于项目申请。先在项目官网确认接受的考试、总分、单项、有效期和最晚提交时间，再决定备考哪一种。不同学校对线上考试、拼分、单项重考和语言班的规定可能不同，考试机构宣布“可用于留学”不等于目标项目一定接受。

## 常见考试

| 考试                        | 主要用途                   | 适合先查看的情况                             |
| --------------------------- | -------------------------- | -------------------------------------------- |
| [雅思 IELTS](./ielts)       | 英语授课项目与部分签证场景 | 目标分布在英国、澳大利亚、欧洲及亚洲英语项目 |
| [托福 TOEFL iBT](./toefl)   | 英语授课项目               | 目标项目明确接受托福，且更适应其机考结构     |
| [PTE Academic](./pte)       | 英语授课项目与部分签证场景 | 项目接受 PTE，且需要较灵活的机考安排         |
| [日语能力测试 JLPT](./jlpt) | 日语能力证明               | 申请日本日语授课项目或需要日语能力证明       |

## 选择方法

1. 从项目表统计各考试的接受范围，不凭地区印象决定。
2. 分别完成一次官方样题或完整模考，比较题型适应度。
3. 核对所在城市考位、出分时间、送分方式和重考成本。
4. 只主攻一种英语考试；达到门槛后，再判断刷分能否改变录取或奖学金结果。

日本申请可能同时涉及 JLPT、英语成绩、研究计划和校内考核。JLPT 不能替代项目要求的其他材料。

> 最后核验：2026-08-20。费用、考位和考试结构可能调整，报名时以考试机构与教育部教育考试院页面为准。
