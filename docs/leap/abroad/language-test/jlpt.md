# 日语能力测试 JLPT

JLPT 分为 N5 至 N1，N1 最高。考试评价语言知识、阅读和听力，不包含口语与写作。它可以证明日语水平，但不能代替大学自行要求的英语成绩、研究计划、面试或校内考试。

## 报考基础信息

- 中国大陆报名、考点与考试安排：[教育部教育考试院 JLPT 报名网站](https://jlpt.neea.cn/)
- 等级与能力说明：[JLPT Level Summary](https://www.jlpt.jp/e/about/levelsummary.html)

## 申请前核对

日语授课项目常会明确要求或参考 JLPT 等级，英语授课项目也可能在实验室沟通、实习和求职中需要日语。先查看研究科招生简章和导师要求，再确定目标等级；不要把“有 N1”理解为自动满足学术与专业门槛。
