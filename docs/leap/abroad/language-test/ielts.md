# 雅思 IELTS

留学申请通常使用 **IELTS Academic（学术类）**。考试包含听力、阅读、写作和口语；纸笔与机考的题目和评分标准一致，考试安排和出分节奏可能不同。

## 报考基础信息

- 中国大陆报名、考位、费用和成绩服务：[教育部教育考试院雅思报名网站](https://ielts.neea.cn/)
- 考试类型说明：[IELTS 官方 Test types](https://ielts.org/take-a-test/test-types)
- 学术类考试结构：[IELTS Academic test format](https://ielts.org/organisations/ielts-for-organisations/test-types/ielts-academic-test/academic-test-format-in-detail)
- 纸笔与机考方式：[Ways to take IELTS](https://ielts.org/take-a-test/why-choose-ielts/ways-to-take-ielts)

## 申请前核对

项目是否接受 Academic、总分和单项分别要求多少、能否后补语言、是否接受单项重考，以及签证场景是否要求特定考试类型。不要用学校层面的最低英语要求代替具体项目要求。
