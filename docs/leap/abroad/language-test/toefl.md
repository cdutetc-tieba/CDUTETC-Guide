# 托福 TOEFL iBT

TOEFL iBT 用于证明英语听、说、读、写能力，许多英语授课项目接受。考试结构在 2026 年已有调整，不要继续沿用旧备考资料中的固定题量和时长。

## 报考基础信息

- 中国大陆报名、考位与费用：[教育部教育考试院托福报名网站](https://toefl.neea.cn/)
- 当前考试与常见问题：[ETS TOEFL iBT FAQ](https://www.ets.org/toefl/test-takers/ibt/faq/about-toefl-ibt.html)
- 考试方式与报名入口：[ETS Testing Options](https://www.ets.org/toefl/test-takers/ibt/about/testing-options.html)

## 申请前核对

确认项目接受的 TOEFL 类型、最低总分和单项、成绩送达截止日，以及是否接受拼分或在家考。使用模考判断自己是否适应综合任务和全程机考，再决定是否从雅思切换。

> 最后核验：2026-08-20。
