# 飞跃手册

## 写在一切之前的话

飞跃手册讨论从本科走向下一阶段时需要面对的选择，也为真实的升学、就业和留学经历保留位置。

在具体经验逐渐积累以前，我们先处理那些经常被准备过程掩盖的问题：为什么选择一条路，它实际提供什么，需要承担哪些成本，以及一个人的成功经验能够借鉴到什么程度。案例栏目只收录能够确认来源的真实投稿；现有示例仅用于展示投稿格式，不能作为决策依据。

## 版块导航

- **考研**：备考经验、院校选择、复试技巧
- **留学**：语言考试、选校申请、文书写作
- **就业/实习**：简历面试、行业分享、实习经历
- **个人总结**：各院系同学的经验分享
